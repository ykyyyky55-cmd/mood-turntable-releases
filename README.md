# 무드 턴테이블 — 설치 파일

다른 앱(스포티파이·유튜브·멜론 등)에서 재생 중인 음악을 파스텔 턴테이블 · CD 플레이어 · 카세트로 보여 주고, 손으로 조작하는 앱입니다.

- **갤럭시 탭(안드로이드)**: 최신 릴리스의 `MoodTurntable-x.y.z.apk`
- **윈도우 PC**: 최신 릴리스의 `MoodTurntable-Setup-x.y.z.exe`

[최신 릴리스 받기](../../releases/latest)

## 업데이트

0.4.0 부터는 설치한 앱이 새 버전을 알아서 받아 업데이트합니다.

- PC: 받아 두었다가 앱을 끌 때 설치합니다(화면 아래 띠를 누르면 바로).
- 태블릿: 앱을 켤 때 새 버전을 받아 설치를 시작합니다. 처음 한 번은 '이 앱에서 설치 허용'과 설치 확인이 필요합니다.
  삼성 태블릿은 **설정 → 보안 및 개인정보 보호 → 자동 차단**이 켜져 있으면 설치가 막힙니다.

이 저장소에는 설치 파일만 있습니다.
